# miniDeck

Mini macropad created to make typing easier. One of the keys toggles Handy's STT. The other one opens the Arduino IDE. Great and easy project for begginers. This was my first time soldering and I was quite pleased it worked first try.

# ⚒️ Components

- 1x ESP32 DEVKITV1
- 2x Mechanical switches
- Soldering iron
- Wiring
- Tin


Note: The glue dots shown in the picture are used so the top of the case doesn't slip. Also, the holes for the switches are quite tight, you may file it a little bit.
